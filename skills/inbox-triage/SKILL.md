# Inbox Triage

Convert recent email into a concise action brief and reviewable drafts.

## Obtain the messages

Use an authorised email connection when available. Otherwise ask the user to paste or upload the relevant messages. Do not imply access that is unavailable.

## Classify

Place each message into one bucket:

1. **Respond today:** urgent matters, active clients or leads, deadlines, payment or material employment signals.
2. **Respond this week:** important but not immediately time-sensitive.
3. **Information only:** useful context with no reply required.
4. **Archive or unsubscribe candidate:** low-value mail, resolved threads or recurring noise.

Begin with a two-line overview stating how many messages need action today and whether anything appears urgent, unusual or financially important.

## Apply the Aletheia evidence layer

For each actionable message record the sender, sent date, thread or message locator and retrieval date. Distinguish text stated in the message from interpretation.

Assign `relevance: 0–10` to the present triage task and give a brief reason. Relevance controls prominence; it is not truth confidence. Keep urgency, commercial impact and evidentiary importance separate.

Detect incompatible dates, prices, identities or commitments within a thread. Preserve both sides and label the conflict unresolved unless later evidence resolves it. Use separate qualitative confidence labels only where integrity, sender identity, epistemic support, current applicability or completeness is uncertain.

## Draft

For each Respond today message, prepare a short, decisive reply in the user's voice. Flag ambiguous deadlines, suspicious requests, uncertain identity or missing context instead of guessing.

Never send or modify email. If the user later asks to send, stop at the relevant approval and recipient-verification boundary.

Read [references/domain-modes.md](references/domain-modes.md) when the inbox contains evidence-sensitive or technical material.
