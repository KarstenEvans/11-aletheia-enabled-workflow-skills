# Content Repurposer

Create distinct derivatives rather than duplicating one text across platforms.

## Learn the formats

When adequate examples are unavailable, ask for two or three successful examples from each target platform. Learn the user's actual hooks, pacing, paragraph length, structure and calls to action instead of substituting generic platform conventions.

## Analyse the source

Record the source creator, publication or recording date, retrieval date and useful locators such as page, paragraph or transcript timestamp. Extract concrete examples, numbers, strong explanations, contrarian observations and memorable moments.

Score candidate moments `relevance: 0–10` for the requested audience and output. Relevance is selection metadata, not confidence. Do not flatten the source into a vague summary.

Preserve material contradictions or qualifications. If a later source supersedes an earlier claim, date and qualify the derivative instead of silently harmonising the sources.

## Produce the requested set

Normally offer:

1. One LinkedIn post following the user's demonstrated structure.
2. One email or newsletter section.
3. One short blog draft when the source has enough substance.
4. Three short-form hooks for social or video openings.

Use the Humanizer skill when available. Do not fabricate facts, experiences, quotations, data or citations. Mark details requiring verification. Separate each deliverable clearly and make it ready to paste.
