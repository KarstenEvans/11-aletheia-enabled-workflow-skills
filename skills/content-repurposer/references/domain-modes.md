# Domain modes

## BIM and engineering automation

Prioritise concrete workflows, version-specific changes, code or API examples, interoperability consequences and practical tests. Link claims to official documentation where available.

## Aletheia

Preserve the distinction between principles, normative protocol requirements, profiles, proposals, decisions, tests and examples. Do not present an unaccepted proposal as protocol.

## Local business and GEO/AEO

Create useful local-service explanations, FAQs, location or access information, authentic customer concerns and citable answers. Avoid unsupported superlatives and generic wellness claims.

## Investigations and evidence-led posts

Do not trade accuracy for engagement. Preserve dates, source limitations, conflicts and uncertainty even when the output must be shorter.
